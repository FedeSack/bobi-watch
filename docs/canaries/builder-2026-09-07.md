# Protected Builder canary

This public, non-product document verifies the protected BobiWatch delivery path.

The reviewed staging commit must be reconstructed by GitHub Actions as one bot-authored commit on a fresh documentation branch whose direct parent is the current `develop` head. The resulting pull request must pass the exact Builder policy check and receive an approval from a different GitHub identity before it can merge.

The canary does not activate providers, deploy software, publish a release, handle credentials, or change Watch, Bridge, or Pairing behavior.
